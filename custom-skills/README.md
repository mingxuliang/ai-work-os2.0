# Custom / business skills (Workspace Resources)

Place enterprise skills here (e.g. `online-learning-bidding/`).  
`deploy/qw2/migrate_qw2.py --skills` copies them into `WORKING_DIR/skills` and
`WORKING_DIR/custom-skills`, and ensures `WORKING_DIR/cache/biaoshumuban` exists
for bidding templates (Governance allows these paths by default).
